# 🛡️ Notas de Cibersegurança

![Notas de Cibersegurança](notasciberseguranca.gif)

Blog minimalista sobre segurança digital, desenvolvido como um laboratório prático para consolidar fundamentos de Front-end (HTML, CSS e JavaScript).

👉 **[Acesse o projeto online](https://samaravs.github.io/Notas-de-ciberseguranca/)**

---

## 🎯 O Projeto
Este site funciona como um diário de estudos onde traduzo termos técnicos de cibersegurança para uma linguagem acessível. O foco técnico do projeto foi a criação de uma interface moderna e funcional utilizando exclusivamente **tecnologias nativas**, sem o uso de frameworks ou bibliotecas externas.

### Principais Funcionalidades
- 🔍 **Busca Instantânea**: Filtro de artigos em tempo real via JavaScript.
- ⏱️ **Leitura Estimada**: Cálculo dinâmico baseado no volume de texto de cada post.
- 📱 **Mobile First**: Design 100% responsivo e otimizado para leitura em qualquer dispositivo.
- 🚀 **Performance**: Carregamento ultra-rápido utilizando imagens WebP e código otimizado.

---

## 🛠️ Tecnologias
- **HTML5:** Estrutura semântica focada em SEO e acessibilidade.
- **CSS3:** Variáveis globais, Flexbox e CSS Grid para um layout moderno e dinâmico.
- **JavaScript:** Manipulação de DOM e lógica de filtragem nativa.

## 🚀 Como rodar localmente
1. Clone o repositório:
   ```bash
   git clone https://github.com/samaravs/Notas-de-ciberseguranca.git
   ```
2. Acesse a pasta:
   ```bash
   cd Notas-de-ciberseguranca
   ```
3. Abra o arquivo `index.html` em seu navegador.
